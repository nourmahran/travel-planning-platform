# Travel Planning and Booking Platform

Software Project I — Winter 2026

German International University

## Project Description

A web-based platform for flight booking, hotel booking,
itinerary planning, budgeting, and travel-content sharing.

## Technology Stack

- Backend: NestJS and TypeScript
- Frontend: Next.js, React, and TypeScript
- Database: MongoDB Atlas
- Payments: Stripe Test Mode
- Currency Conversion: FXRatesAPI
- API Documentation: Swagger UI

## Project Structure

- backend/ — NestJS backend
- frontend/ — Next.js frontend
- docs/requirements/ — Project requirements
- docs/api/ — API documentation
